Paper Reed 隐私政策

生效日期：2026-11-24

Paper Reed 是由 开源项目维护者 macopc 维护的桌面邮件客户端。本政策说明 Paper Reed 如何处理连接邮箱时获得的数据。

访问的数据与用途

连接 Gmail 时，Paper Reed 使用 Google 提供的账号标识及邮箱地址识别所连接的账号。你授予 Gmail 邮件权限后，应用可读取文件夹、标签、邮件头、正文、附件和草稿，用于同步、搜索、阅读、整理、写信和发信。当前版本通过 IMAP 同步 Gmail，并通过 Gmail API 发送邮件。

存储与共享

Paper Reed 从本机直接连接邮箱服务商。用于搜索和显示的邮件副本、索引、草稿和账号设置保存在本机，Google 刷新凭据在本机加密保存。Paper Reed 不运营用于集中存储这些邮箱数据的服务器。发送邮件时，你选择发送的内容和附件会交给邮箱服务商投递给收件人。

如果你启用 Agent 连接，Paper Reed 会通过本机接口向你选择使用的 Agent 提供其获准读取的邮件或草稿。你可以在设置中限制允许访问的邮箱和操作。若该 Agent 使用云端模型或其他远程服务，它可能将读取或收到的内容交给其服务提供方处理，其处理方式取决于该服务的设置和政策。

Paper Reed 对从 Google API 收到的信息的使用和传输遵守 Google API 服务用户数据政策，包括 Limited Use 要求。

保留、删除与撤销授权

本机邮件缓存供已连接的账号使用。你可以在 Paper Reed 设置中移除账号，应用会清理该账号的本机缓存和凭据。也可以在 Google 账号的第三方连接 撤销 Paper Reed 的访问权限。邮箱服务商、收件人或外部 Agent 已保留的副本，由相应服务或收件人管理。

如对数据处理、访问或删除有疑问，请通过 GitHub 问题反馈 联系维护者。这是公开渠道，请勿上传邮件内容、授权令牌或账号凭据。
