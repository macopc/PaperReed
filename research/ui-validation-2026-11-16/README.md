# Paper Reed 界面接通邮件核心

这是实验桌面界面，不是已验收的首版客户端。沿用 [现有设计基线](../../design/INTERFACE.md)，补充 [编辑状态规格](../../design/EDITOR-STATES.md)，通过 [0007 补丁](../patches/0007-connected-workspace.patch) 接到原来的数据库、草稿会话、隔离邮件正文渲染器和富文本编辑器。没有新增服务端、数据库或另一套发送队列。

## 本轮实现

- 纸白与苇绿的收件箱、草稿、已发送、垃圾邮件和废纸篓；真实查询、账号范围、发件人头像色环、摘要及分批加载。
- 列表进入会话，内联回复与独立写信共用编辑器及 640px 版心。新安装的实验界面不自动插入上游推广签名，已有用户签名保留。
- 编辑区持续显示未保存、保存中、本机已保存和版本冲突。切换页面先保存，失败时留在原页面。
- 冲突时直接另存副本，保存成功后可以打开副本，或明确选择“保留副本，载入最新原稿”。复制后若又有输入，必须再存新副本，不能用旧副本放行覆盖。
- 发送结果从原有持久操作表查询；折叠摘要仍显示最近结果，区分服务器接受、已发送副本归档、失败与结果未知。
- 首页、会话和草稿提供 Agent 上下文入口。保存成功后复制当前引用；草稿带版本号。连接入口打开原有 MCP 设置，返回邮件后恢复当前页面。

## 验证与证据

检查入口：[check-paper-reed-ui.cjs](../harness/check-paper-reed-ui.cjs)。使用实际 Electron、实验 CLI、桌面 MCP、自编译同步引擎及本机 IMAP / SMTP 服务。没有 `PLAYWRIGHT` 模拟模式。CDP 只用于驱动窗口、设定视口和读取断言；正文输入与按钮通过真实页面交互完成。设置返回使用现有页面切换 Action。

截图使用 1440×900 和 900×700 的渲染视口，不代表两块真实显示器。样本为 8 封虚构邮件和测试草稿。网络限制保持仅 loopback，不会接入或发送到真实邮箱。

复现前，按 [补丁说明](../patches/README.md) 准备固定上游版本、依赖、自编译引擎及 0001–0007 补丁。当前工作区已应用，不要重复应用。

```sh
sandbox-exec -f research/harness/loopback-only.sb \
  research/.local/venv/bin/python research/harness/check-compose-handoff.py \
  --upstream research/.local/Mailspring --workspace
```

自动检查覆盖真实收件箱、紧凑列表、隔离正文、内联回复、CLI 草稿打开、GUI 未保存输入与 CLI 新版本冲突、导航阻止、副本保存、复制后继续编辑保护、明确载入最新原稿、交接版本、设置返回、GUI 发送和持续结果。SMTP 端额外确认只投递一次、To/Cc/Bcc 三个收件人及无 Bcc 邮件头。运行摘要保存在 [result.json](result.json)，页面证据见 [截图对照](index.html)。

另运行完整上游 TypeScript 检查、草稿与恢复边界检查，以及仓库文档／页面生成检查。异常保存和原有窗口关闭路径不因新界面而放宽。

## 仍有明确缺口

1. 这是接通核心的第一层界面，尚未达到设计稿完成度。收件人、格式栏、部分菜单与弹窗仍来自上游，存在英文文案、控件密度及细节风格不统一。独立弹出写信窗口没有完成同等视觉打磨。
2. 副本内容可恢复，但列表中尚无持久的“恢复副本／来源”标记。同主题副本仍需进入检查正文。附件副本暂不支持，失败时保留原编辑，不能丢弃附件。
3. 本地置顶、稍后、标签、规则、全局搜索和完整快捷键体验未接通；没有放置假入口。当前账号色使用固定调色板，尚未接入设计稿的自定义设置。
4. Agent 仅复制引用并打开真实连接设置；不是 CLI 安装器，也不会自动启动 Claude Code、Codex 或 OpenCode。真实多账号、权限配置及一键交接仍待验证。
5. 发送展示基于已有操作表，尚未完成完整历史、取消、离线反馈和所有失败状态的 UI 验收。当前端到端用例验证接受并归档；未知结果的协议语义由先前引擎检查覆盖，不能据此声称未知状态页面已实测。
6. 没有验证真实服务商 OAuth、凭据刷新、长期同步、大邮箱性能、VoiceOver、正式打包、签名与公证。列表摘要目前逐会话查询最近邮件，适合此轮小样本，后续应复用批量数据源后再做大邮箱性能结论。

下一轮应先评审这些实际页面，优先收敛编辑器布局和副本辨识，再扩展邮箱能力。当前实现不能代替设计批准。
