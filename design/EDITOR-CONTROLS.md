# 收件人、签名与格式工具

在 `8d1282f` 的实际编辑器上继续打磨。保持纸白、苇绿和 640px 版心，复用联系人查询、签名存储和现有富文本编辑器，不另建编辑系统。

| Before | After | Why |
| --- | --- | --- |
| 补全项姓名、地址挤在一行，选中亮蓝 | 两行姓名／邮箱，苇绿选中底色，与输入值列对齐 | 同名联系人用地址辨认；选择态与全局一致 |
| 已选收件人只有姓名，选中后沿用反白文字 | 悬停可查看完整地址，选中保持可读；无效地址保留独立红色提示 | 不用颜色猜身份，不把错误样式在重绘中抹掉 |
| 旧搜索晚到可覆盖新结果，Esc 取消仍可能弹回 | 只采用最后一次查询，取消即作废待返回结果 | 减少选错收件人的风险；不改联系人来源或搜索排序 |
| 签名是图标，菜单仅列名称 | “签名 + 当前选择”；菜单提供纯文本摘要和选中标记 | 能看到要插入的内容；长签名名截断但可查看完整标题 |
| 签名无键盘入口，空状态含糊 | 原生可聚焦控件，方向键选择，Esc 返回入口，明确空状态和管理入口 | 用键盘完成插入、替换和移除，正文不受影响 |
| 格式栏英文提示混杂，颜色块突兀 | 工具分组、中文名称、可见焦点与按下状态，文字颜色用带色线的 A 表示 | 保留全部既有格式能力，减少识别成本 |
| 链接输入不支持 Esc，部分工具只响应鼠标 | 链接支持键盘确认／取消；格式按钮支持键盘激活 | 保留原文选区，在指定文字上应用格式 |
| 配色面板展示大量鲜艳色块 | 八个常用颜色及系统自定义颜色入口 | 默认选择克制，保留任意颜色的能力 |

## 行为边界

签名仍使用原有插入／替换逻辑、账号默认设置和管理页面；预览只显示文本，不执行签名 HTML。不会修改账号默认签名，不会自动给新用户加推广签名。旧正文中存在但已从设置删除的签名显示“已有签名”，而不是误报为“无”。

格式栏展开、收起不改变正文格式。没有重写 Slate、增加通用浮层系统或替换联系人数据源。补全的时序与输入法保护、格式按钮的键盘激活属于共用组件修正；Paper Reed 的视觉与签名选择器通过原有开关启用。

## 后续仍需评审

签名管理设置页、表情选择器、系统自定义颜色窗口尚未整套重绘。长联系人列表、复杂 HTML 签名、真实多账号切换和 VoiceOver 仍需覆盖；本轮合成输入法事件检查不等于真人中文输入法验收。补全的无结果／查询失败反馈也尚未单独设计。

实际证据和复现步骤见 [控件验证](../research/controls-validation-2026-11-16/README.md)。
