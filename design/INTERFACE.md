# Paper Reed · 纸白与苇绿

第八版，设计候选，尚未通过评审。架构和技术选型仍未确定；本轮只更新示例数据交互原型。[上一版原型](direction-v7.html)与[上一版说明](INTERFACE-v7.md)完整保留。

## 方向

面向每天在几个邮箱之间阅读、回复、整理邮件的人，也方便他们把具体邮件交给常用的外部 Agent。希望长时间使用时安静、清楚、有自己的气质。

Paper 对应信纸的底色、页边距和阅读节奏；Reed 对应苇绿、纤细的竖线与字标中的芦苇。领域意象来自信笺、页边、折起的来信、书签、手写签名与纸张边缘。它们影响排版，不变成每个页面的装饰。

这一版的识别点是衬线字标与细苇标记，以及贯穿导航选中、邮件焦点、回复编辑区的细绿竖线。正文和控件使用系统无衬线字体。避免铺满纸纹、大片绿色、邮票图案，也避免用卡片和徽章重复包裹每条信息。

## 页面结构

- 顶栏：Paper Reed 字标、账号范围、命令入口。账号范围只在可筛选邮件的列表与搜索页显示；搜索和列表共用同一范围，切换不改变当前位置。会话、写信与设置页保留自己的上下文。
- 左侧常驻导航：搜索入口，以及邮箱位置、留待处理、标签三组；底部是外部 Agent 和邮箱偏好。导航用文字与间距区分，不给每一项堆叠图标。窄窗口保留收件箱搜索按钮和命令入口，搜索图标与命令图标区分职责。
- 邮箱位置包含收件箱、草稿、已发送、归档、垃圾邮件、废纸篓；置顶和稍后是整理视图。
- 收件箱的全部、往来、通知、订阅只表示分类。自定义标签独立于文件夹；规则页支持匹配预览与可选的已有邮件处理。
- 会话和写信使用相同的 640px 正文区域、标题和正文排版。回复直接在会话末尾展开。
- 原型底部的页面切换条仅用于评审，不属于产品导航。

发件人、主题、摘要、时间各有固定职责。账号色仅作用于头像外圈；标签短而轻，并在紧凑布局保留；附件只在存在时显示。长主题省略，不挤走标签、时间和附件；进入会话后完整换行。页面标题与操作区在正常布局内避让，长标签名可换行。订阅仍为可展开的汇总行。

列表按主内容区的实际宽度切换结构：600px 以下采用三层纵向排布。这个容器断点独立于导航和留白的视口断点，900px 分屏仍可保留横向发件人与主题列。700px 以下导航折叠为抽屉，勾选框占行内独立一列，选中底色包含勾选框。稍后页只提供恢复操作，不显示没有批量操作出口的勾选框。更窄的预览用于检查内容收缩，不代表本轮扩展为手机产品。

原型外窗随可用视口收缩，上限为 830px；底部评审切换条按实际换行高度参与布局，长列表和设置页在主内容区域滚动。矮窗口收紧侧栏组间距，导航点击区仍至少 32px。正文和设置的版心、字号与行距沿用原有规则，密度修订集中在邮件列表。

搜索结果统计和稍后日期标题沿用列表的水平起点；稍后列表共用发件人列宽与行间分隔线。收紧订阅汇总外距，并将水平内边距移至汇总按钮，避免展开邮件额外缩进。

## Agent 路径

收件箱、会话、写信和回复动作区保留轻量文字入口。未安装时显示“连接 Agent”；模拟安装后显示“交给 Agent”。Agent 设置页以一张简洁的安装引导区域开头，然后是客户端、操作权限和邮箱范围。

交接沿用当前邮件、明确勾选的邮件、搜索结果或当前草稿；不要求用户重新搜索上下文。CLI 安装与 Agent 配置仍是两个状态，配置后恢复原来的任务文字、邮件范围和回复编辑状态。设置页只安装与配置，不隐式交接收件箱。未经授权的邮箱不可交接。Agent 标记使用与其他界面图标同源的 SVG。详细流程与尚未确定的实际启动机制见 [AGENT-HANDOFF.md](AGENT-HANDOFF.md)。

## 原型行为和边界

已有的搜索、分类、标签、规则预览、批量整理、撤销、草稿保留、账号标记自定义与 Agent 演示继续可用。快捷键包括 J / K、Enter、Escape、E、P、H、R、C 和 ⌘K；输入与中文组词优先，弹窗支持焦点循环。

勾选邮件后，E 与命令面板归档同一选择集；单封操作 P / H / R 提示先取消勾选。草稿列表直接打开写信编辑，恢复抄送、附件名称与大小，以及正文原始换行；回复草稿直接展开到对应会话末尾。

所有操作只影响当前原型的内存数据。刷新恢复初始状态；不安装 CLI、不启动 Agent、不接入邮箱、不发送邮件。附件只保存本机选择的名称和大小，不上传。示例日期固定为 2026-11-14，正式产品需使用实际时间与系统时区。

本轮顺带纠正了垃圾邮件 / 废纸篓会话误显示稍后提醒的问题。邮件 HTML 隔离、富文本、真实授权、同步和窗口实现仍属于后续技术验证。

## 标签颜色联动

同一个标签在侧栏、管理页和邮件行共用自定义颜色。侧栏保留原色小色块与墨色文字；邮件行标签使用 20% 标签色与纸白混合的浅底，文字使用 25% 标签色与墨色混合的深色。标签色不改变发件人、主题、整行选中背景或账号头像色环。选中行仍显示同一标签底色，便于跨状态识别。字号与行距保持 11px / 16px，不增加邮件行高。
