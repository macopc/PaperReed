Paper Reed 服务条款

生效日期：2026-11-24

Paper Reed 是由 开源项目维护者 macopc 维护的开源桌面邮件客户端。源码使用条件见 仓库许可证。

请只连接你有权访问的邮箱，遵守适用法律、邮箱服务商的条款和所在组织的邮件使用规则。使用 Agent 整理邮件、修改草稿或发信时，请按任务所需设置访问范围，发送前核对收件人、内容和附件。

邮件同步与投递依赖邮箱服务商。启用外部 Agent 时，该服务也适用其自己的条款和隐私政策。Paper Reed 的邮箱数据处理方式见 隐私政策。

如有使用问题，请通过 GitHub 问题反馈 联系维护者。
