# 首版编辑状态与页面连接

本轮将已选的纸白与苇绿界面接入实验邮件核心。收件箱保留 168px 导航、32px 账号色环头像和 68px 邮件行；阅读与编辑共用 640px 版心。品牌使用 Iowan Old Style，内容使用系统字体。纸白 `#faf9f6`、内嵌 `#f2f1eb`、墨色 `#303730`、辅助文字 `#626b60`、苇绿 `#4b634f`、选中 `#e9eee5` 沿用现有设计。

编辑状态占正文上方一行，不靠弹窗或短暂 toast 告知。正常状态安静显示；异常增加说明与操作，不改变正文位置与输入内容。

| 状态 | 显示与行为 |
| --- | --- |
| 有未保存编辑 | “尚未保存”；保留编辑，空闲后自动保存，也可立即保存 |
| 正在保存 | “正在保存…”；等待真实保存回执，期间新增输入仍视为未保存 |
| 保存成功 | “已保存到本机”；不暗示已经同步到邮箱服务商 |
| 保存失败 | “尚未保存，请重试”；编辑保留，可重试 |
| 草稿版本冲突 | “其他窗口或 Agent 更新了这封草稿。你的编辑仍保留在这里。”；提供另存副本，不能覆盖原稿或直接发送 |
| 副本保存成功 | 显示“副本已保存”，可打开副本；原编辑区保持不变。继续修改后允许再存一份，不能把较早副本称作当前编辑的副本 |
| 副本保存失败 | 说明失败，保留原编辑；附件副本未支持时明确说明，不丢弃附件 |
| 发送处理中 | “正在发送”；以持久发送操作状态为准，不以编辑器关闭为成功 |
| 邮件服务器已接受 | “服务器已接受”；另行标明已发送副本是否归档，不承诺对方已收到 |
| 发送结果未知 | “发送结果待确认”；不提供一键重试，先检查邮箱，避免重复发送 |

点击侧栏、返回或新建前，先保存本窗口尚未保存的草稿。失败时停留原页面，显示可处理的状态。外部 Agent 入口在草稿仍未保存时不能交接旧版本。

首个接通版本提供收件箱、草稿、已发送、垃圾邮件和废纸篓的真实查询，列表进入会话，草稿进入编辑，回复沿用同一编辑器。未接通的本地置顶、稍后、标签、规则和全局搜索不放置可点击的假入口。列表分批加载，不声称有限结果是全部邮件。

Agent 首先提供明确的上下文复制与连接设置；这不等同于已安装 CLI、已配置某个 Agent 或已经启动任务。自动安装和启动方式另行验收。账号色环用作账号辨识，不表示未读；未读另用独立圆点和文字描述。

恢复副本现在具有本机持久来源、稳定编号和创建时间，列表区分原稿／副本，编辑器提供“查看原稿”。来源已发送或不再可读时说明原因并保留副本；编号不随删除重排，标记不进入邮件主题或邮件头。已完成两份副本、重启、来源不可用及删除后的实际界面验证。完整发送历史、真实多账号、离线状态和键盘全路径仍需单独验证。实验界面不因此被视为首版产品完成。
