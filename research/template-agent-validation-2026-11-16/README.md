# 邮件模板与 Agent 设置

上一轮已提交并推送为 `7c4a960`。本轮源码见 [0015 补丁](../patches/0015-template-agent-settings.patch)，在桌面 0014 后应用，无需重编译原生引擎。

| Before | After | Why |
| --- | --- | --- |
| 模板列表、标题与正文层级薄弱 | 名称／主题列表与编辑区分层，明确离焦保存、主题保留和删除语义 | 方便寻找和维护常用表达 |
| 模板名字排除中文，改名可覆盖已有文件 | 支持 Unicode 字母、组合字符和数字，拒绝已有文件名 | 中文名称可用，并保留已有模板 |
| Paper Reed 写信工具栏没有模板入口 | 文字“模板”入口复用原选择器与插入流程 | 设置中的模板能够直接用于草稿 |
| 设置内格式栏没有沿用编辑器样式 | 共用现有格式工具样式，正文内边距仅作用于编辑区域 | 让写信与模板编辑一致，避免误放大内联变量 |
| Agent 配置、令牌和工具记录混在一起 | 按连接状态、权限、邮箱范围、连接方式、记录分组 | 先理解授权范围，再完成连接 |
| 账号勾选与展开操作重叠 | 独立复选框与“选择文件夹”按钮 | 避免修改权限时意外展开或收起 |
| 令牌明文展示，端口边输边应用 | 默认遮盖令牌，端口显式应用，令牌更换可取消 | 保持连接操作可理解、可控制 |

沿用 TemplateStore、HTML 模板文件、ComposerEditor、MCP manager 和原有权限服务；没有新增服务、数据库或第二套模板引擎。新布局由 Paper Reed 开关控制；模板名称和文件写入错误修正也适用于原有界面。

## 已验证

真实 Electron 窗口、实验 CLI/MCP、原生同步引擎和本机 IMAP/SMTP 夹具，独立配置及 loopback-only 沙箱。**SMTP 提交数为 0**。

- 模板：新建中文模板；改名；主题和正文离焦保存到 HTML；重名拒绝且原文件不变；失败后名称输入恢复；删除取消与确认。
- 写信：通过工具栏选择实际模板，确认替换已有正文，提交共用草稿会话；CLI 读回相同主题和正文。
- 令牌：默认 password 输入；显示／隐藏；复制地址和令牌分别得到正确值。复制测试拦截剪贴板最终写入，没有替换用户剪贴板。
- 权限：只读模式真实拒绝 CLI 创建草稿；“阅读与草稿”允许；禁用账号和排除草稿文件夹均阻止草稿读取，恢复后能读取原草稿。
- 连接：非法端口不能应用；实际切换本机监听端口后恢复；更换令牌取消不生效、确认后旧令牌返回 401；关闭连接后监听停止，再开启恢复监听。
- 记录：调用记录可展开详情和清空；记录仍只保存在当前会话内存中。
- 1440×900 与 900×700 实际截图；两页均无横向溢出，模板格式栏在窄窗口折行。
- TypeScript 检查通过。13 份桌面补丁从固定基线顺序应用，55 个文件与实验源码逐字节一致。

## 边界

Agent 页提供手动 HTTP MCP 地址、令牌及实验 CLI 文档入口；没有声称提供一键安装，也没有执行 Claude、Codex、OpenCode 配置写入或完成这些客户端的安装验收。CLI 仍需按文档准备依赖和连接参数，Paper Reed 必须运行。

本轮不发送邮件，不重复验收所有整理与发送工具；真实多账号、完整 VoiceOver、复杂模板变量／HTML、磁盘写入失败和多窗口同时编辑仍需专项验证。模板使用原有离焦保存机制；记录不是持久审计日志。没有增加账号默认授权语义或自动化规则。
